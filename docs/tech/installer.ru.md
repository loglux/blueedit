# Установщик для Windows (`tools/installer`)

English: [installer.md](installer.md).

Кроме zip (один самодостаточный `be.exe` и скрипты установки) в каждом релизе есть
`blueedit-<версия>-win-x64-setup.exe`. Его собирает [Inno Setup 6](https://jrsoftware.org/isinfo.php) из
`tools/installer/blueedit.iss` (`tools/installer/build.ps1`; локально `.\tasks.ps1 installer`, для тега —
`release.yml`). Добавлен 23 октября 2026 года.

## Что он делает

| | |
|---|---|
| Куда | `%LOCALAPPDATA%\Programs\BlueEdit`: `be.exe`, `tools\proofing-setup`, `tools\lsp-setup`, `LICENSE.txt`, `THIRD-PARTY-NOTICES.md` |
| Всегда | ярлык в «Пуске»; строка в «Программах и компонентах» (удаление); App Paths (Win+R `be`); список «Открыть с помощью» Проводника для `.txt`, `.md`, `.markdown`, `.log`, `.json`, `.ini`, `.py`, `.cs` |
| Отмечено заранее | `be` в PATH пользователя; «Открыть в BlueEdit» в меню любого файла в Проводнике |
| Не отмечено | ярлык на рабочем столе; языковые серверы для кода |
| Проверка грамматики (отдельная страница) | ничего не выбрано: Harper, LanguageTool, языковая модель здесь (одна из пяти, по видеокарте) или сервер моделей (адрес, модель, ключ) |
| Языки | английский и русский, по языку интерфейса Windows (если ни тот ни другой — спрашивает) |

Выбранные проверки, модель и инструменты для кода в конце скачивает сам `be.exe` — `be --install-proofing
harper,qwen3-8b`, `be --install-tools pyright` — в отдельном окне консоли, где видна загрузка, а выбранные проверки
грамматики, когда они на месте, он же включает (`be --grammar harper,llm`). Это тот же код, что у
**Tools → Set up grammar checking** и **Tools → Code tools**: те же источники и проверки SHA-256 (`ProofingTools`,
`CodeTools`), те же папки. Если что-то не поставилось, окно ждёт нажатия клавиши, чтобы можно было прочесть, что
именно, а установщик говорит, что сам редактор установлен и эти меню могут попробовать ещё раз. `InstallerTests`
следит, чтобы имена в установщике совпадали с `ProofingTools.Models` и `CodeTools.All`, у каждого был текст на
обоих языках, а видеопамять, названная в строке модели, совпадала с той, что проверяет редактор.

### Страница проверки грамматики

Одна страница после задач; её подзаголовок говорит, что здесь ничего не окончательно — всё можно поменять потом в
редакторе. Три части:

- **Правила, видеокарта не нужна**: Harper (английский), LanguageTool (31 язык) — можно отметить одно или оба.
- **Языковая модель здесь** — одно из: не нужна (по умолчанию) или пять моделей. В строке
  группы — видеокарта и её память. Модель, для которой у карты мало памяти, серая, и сказано, сколько нужно («нужно
  ~8 ГБ видеопамяти»); без видеокарты серые все пять. Лучшая из подходящих по замеру (порядок Auto) помечена
  «рекомендуется»; сама она не выбирается — модель весит гигабайты.
- **Строка под списком** объясняет выделенную строку: в чём проверка хороша, её лицензию, что ей нужно; для сервера —
  что абзацы отправляются туда.

Видеокарту спрашивают у самого `be.exe`, извлечённого из установщика во временную папку, когда пользователь уходит
со страницы задач: `be --video-card` печатает карту («card 12282 NVIDIA GeForce RTX 4070» или «card none»), для каждой
модели «fits KEY» или «needs KEY GB» и «recommended KEY». Карта — та же, что редактор уже находит для llama.cpp
(nvidia-smi, иначе Vulkan в отдельном процессе, `ProofingTools`), плюс её память: `memory.total` из nvidia-smi или
самая большая device-local куча Vulkan. Встроенная карта считается за отсутствие: здесь Vulkan сообщает о памяти
Intel UHD как о 32 ГБ — это память компьютера, которую она занимает, — а модель на ней идёт примерно так же медленно,
как на процессоре. Карта на 8 ГБ сообщает чуть меньше (8188 МБ), поэтому гигабайт считается за 1000 МБ. Если
карту спросить не удалось, можно выбрать любую модель, как в редакторе.

**Модель в другом месте** (в том же выборе одного: OpenAI, Claude (Anthropic), Gemini (Google), DeepSeek, другой
сервис по ключу; Ollama, LM Studio, свой llama-server) добавляет вторую страницу: адрес, предложенный для каждого (у
Ollama `http://127.0.0.1:11434/v1`, у LM Studio `…:1234`, у llama-server `…:8080`, у сервисов — их собственный), и для
сервиса, которому он нужен, ключ (точками). Имя модели никто не набирает: облачный сервис получает ту, что рекомендует
замер плагина для Obsidian (gpt-5.4-mini, claude-haiku-5-5, gemini-3.5-flash-lite, deepseek-flash); свой сервер — никакой,
и редактор берёт модель из его списка (`LlmServer`: первую, у llama-server она одна); **Инструменты → Модель
грамматики** выбирает другую из списка сервера. Ключ необязателен: пустой — ничего не спрашивается, ввести его можно
потом в редакторе. Введённый ключ проверяется на «Далее»: `be --check-model-server` спрашивает у сервиса список моделей
(бесплатно, несколько секунд) и говорит, что нашёл («api.anthropic.com не принял ключ: invalid x-api-key», нет ответа…),
спрашивая, сохранить ли всё равно (Нет, по умолчанию, — вернуться и исправить): установка может идти без сети. Модель и
адрес там не проверяются: что есть на сервере — дело настройки в редакторе. `be --model-server АДРЕС МОДЕЛЬ`
записывает их в настройки так же, как **Инструменты → Настроить проверку грамматики → Другой сервер моделей** (который
проверяет так же, и модель тоже: «нет модели …; есть: …»); ключ приходит к нему в окружении (`BLUEEDIT_LLM_KEY`,
заданной в процессе самого установщика только на этот вызов), никогда в командной строке, где его увидели бы другие
программы и журналы, и попадает в `llm-key`, зашифрованный для пользователя (DPAPI; `proofing-internals.md`).
Страница «Всё готово» перечисляет выбор, сервер — адресом и моделью, ключ — никогда. Под полями — строка на
предложение: собственный перенос надписи рвал русские слова посреди в Windows Sandbox (как и русские тексты самого
Inno: «опц/ии»; на русской Windows не проверено).

Повторная установка поверх (новая версия) помнит прошлый выбор (`UsePreviousTasks` в Inno); если снять галочку PATH,
папка из PATH уходит. **Tools → Command be in any console** в редакторе меняет ту же запись PATH, так что они
не расходятся.

Удаление убирает программу, запись в PATH, ярлыки и ключи реестра и спрашивает, удалить ли и то, что скачал редактор
(`%LOCALAPPDATA%\BlueEdit`: проверки, модели, инструменты для кода; по умолчанию **Нет**, и при тихом удалении
тоже — модели весят гигабайты, качать их заново долго). Настройки и словарь пользователя (`%APPDATA%\blueedit`)
остаются.

Тихая установка, например из скрипта: `blueedit-…-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /TASKS="path,openwith"
/GRAMMAR=harper,yandexgpt` (выбраны ровно перечисленные задачи, имена — в `blueedit.iss`; `/GRAMMAR` берёт имена
`be --install-proofing` и включает их; видеокарта не проверяется, и сервера моделей нет: его ключ оказался бы в
командной строке).

## Почему так

- **Inno Setup, а не MSI или MSIX.** Страница задач с группами и выбором одного из нескольких (модели), запуск своей
  программы в конце и код на Pascal для PATH там есть готовыми; установка для одного пользователя без администратора —
  обычный для него случай; он бесплатный, а компилятор — одна программа (`ISCC.exe`). MSI (WiX) нужен компаниям,
  которые раздают программы через групповые политики или Intune, но своя страница там — гораздо больше работы; пока
  об этом никто не просил. MSIX ставит только подписанные пакеты, а `be.exe` не подписан.
- **Для одного пользователя, без администратора.** Всё, что скачивает редактор (проверки, модели, инструменты для
  кода), и так живёт в `%LOCALAPPDATA%\BlueEdit` пользователя; установка для всех положила бы программу в Program
  Files, а проверки — в профиль администратора. PATH — пользовательский (`HKCU\Environment`), хранится как
  `REG_EXPAND_SZ`, чтобы его `%переменные%` не раскрылись.
- **Качает редактор, а не установщик.** Установщик остаётся маленьким (один сжатый `be.exe`) и работает без сети,
  если ничего не отмечено; а источники, версии и контрольные суммы знает одно место. Скрипты PowerShell тоже
  ставятся (у `install.ps1 -EdgeCanary`, `-ChromeModel` нет аналога в `be.exe`).
- **Ничего большого не отмечено заранее.** Орфография сразу работает через Windows; что добавлять, зависит от языков
  и видеокарты, а модели весят гигабайты.
- **Своя страница для грамматики**, а не список задач, с которого она начиналась: на странице задач нельзя сделать
  строку серой и объяснить почему или спросить адрес и ключ, а модель, предложенная компьютеру без видеокарты, — это
  только впустую скачанные гигабайты.
- **Без подписи**, как и zip: SmartScreen предупреждает о новом скачанном файле, пока у него нет репутации.

## Как проверяется

`.\tasks.ps1 installer-sandbox` (`tools/sandbox/start.ps1 -Installer`, `tools/sandbox/installer.ps1`) собирает
установщик из текущего кода и запускает его в Windows Sandbox, на чистой Windows (около 3 минут):

- тихая установка как есть, которая не должна ничего скачать;
- тихая установка с PATH, «Открыть в» и Harper (`/GRAMMAR=harper`), и каждый результат проверяется (файлы, PATH,
  App Paths, ключи меню, ярлык, скачанный и включённый Harper, `be --version` из PATH новой консоли);
- установка поверх без PATH (запись уходит); тихое удаление (всё убрано, скачанное осталось);
- вся установка по-русски через мастер, Enter на каждой странице, по снимку окна установщика на шаг (лицензия,
  папка, задачи, страница грамматики без видеокарты — все пять моделей серые, —, готово, распаковка, конец), и
  страница задач по-английски;
- страница грамматики, как её видит компьютер с картой на 8 ГБ (`BLUEEDIT_VIDEO_CARD`: в Sandbox карты нет): все пять
  подходят, рекомендована YandexGPT; выбран Claude, введён ненастоящий ключ, Anthropic отвергает его на «Далее», «Да»
  оставляет; затем проверяется: в настройках Anthropic, claude-haiku-5-5 и `file:llm-key`, файл ключа зашифрован, ключа
  нет ни в настройках, ни в журналах;
- выбрана Ollama: адрес предложен, ключ не спрашивается.

23 октября 2026 года установщик весил 25,6 МБ (сам `be.exe` — 72 МБ). Снимки окупились с первого прогона: вложенный
пункт модели или инструментов для кода без пометки `unchecked` отмечает свою группу, поэтому группа модели оказалась
отмечена вместе с Qwen3 8B, а инструменты для кода — все четыре. Нажав «Далее» на каждой странице, человек скачал бы
около 6 ГБ. Тихие проверки называли задачи явно и этого не заметили; теперь это ловит установка как есть.
