# Терминалы и шрифты: формулы без квадратиков

*English version: [terminal-fonts.md](terminal-fonts.md)*

Консольная программа не выбирает шрифт: каждый символ рисует терминал тем шрифтом, что задан в нём. Формулы,
показанные текстом, используют символы, которых нет во многих моноширинных шрифтах: буквенные индексы (`cₙ`), `⩽`, `∈`,
высокие скобки и интегралы (`⎛ ⌠`). Что будет с символом, которого нет в шрифте, зависит от терминала:

- **Windows Terminal** берёт его из другого шрифта (Cambria Math, Segoe UI Symbol), поэтому видна любая формула. Он же
  показывает формулы набранными картинками (Sixel, [formula-pictures.ru.md](formula-pictures.ru.md)). Для формул
  стоит пользоваться им — и на своём компьютере, и по SSH.
- **MobaXterm, ConEmu, классическая консоль Windows** рисуют только своим шрифтом (или одним запасным) и показывают
  квадратик `□` там, где в шрифте символа нет.

## Чего нет в распространённых шрифтах

Измерено fontTools на шрифтах Windows 11 (11 октября 2026):

| Шрифт | Каких символов формул нет |
|---|---|
| Consolas | буквенных индексов `ₕ ₖ ₗ ₘ ₙ ₚ ₛ ₜ`; `⩽ ⩾ ∼ ≃ ≅ ∝ ≪ ≫ ∈ ∉ ⊂ ⊆ ⊃ ⊇ ∪ ∧ ∨ ⊕ ⊗ ∓ ⇒ ⇐ ⇔ ⟹ ∇ ∮ ∛ ∜ ∠`; высоких скобок `⎛ ⎜ ⎝ ⎞ ⎟ ⎠ ⎡ ⎣ ⎤ ⎦` и `⎮` |
| Cascadia Mono | того же, а также всех буквенных индексов и степеней, кроме `ⁿ`, и `⁺ ⁻ ⁼ ⁽ ⁾` |
| Courier New | индексов-цифр `₀ … ₉`, большинства степеней-цифр и тех же символов |
| Lucida Console | всех индексов и большинства степеней и тех же символов |
| Cambria, Cambria Math | всё есть: каждый символ, который использует редактор (но см. ConEmu ниже) |

`≤ ≥ ≠ ≈ ∞ ∑ ∫ √ ± × · → α β π` есть во всех.

## Два выхода

1. **Дать терминалу шрифт, в котором символы есть**, или разрешить брать их из другого (ниже, по терминалам).
2. **Попросить редактор о простых символах**: Tools → Settings → *Formula symbols*: *basic*, или
   `"formulaSymbols": "basic"` в `settings.json`. Тогда буквенные индексы, которых мало где есть, пишутся явно (`c_n`
   или строкой ниже в многострочной формуле), а `⩽ ⩾` показываются как `≤ ≥` (те же отношения в другом начертании).
   У остальных (`∈`, высокие скобки) простой замены нет — они остаются. Настройки у каждого компьютера свои: для
   сервера, куда вы заходите по SSH, это его `settings.json` (`~/.config/blueedit/settings.json`).

По умолчанию — *full*: там, где терминал их показывает, настоящие символы смотрятся лучше замен.

## По терминалам

### Windows Terminal

Ничего делать не нужно. Если Far Manager запускается из меню «Пуск», проверьте, в каком окне он открывается: в Windows 11
это решает *приложение терминала по умолчанию* (Параметры → Система → Для разработчиков → Терминал) — `cmd`, PowerShell
и Far откроются в Windows Terminal (окно с вкладками) или в классической консоли. На тестовой машине там стояло
*Пусть Windows решает* (реестр, 11 октября 2026); что это даёт, не проверялось, поэтому для верности выберите там *Windows
Terminal*.

### Классическая консоль Windows (conhost)

Один шрифт, эти символы из других шрифтов не берутся, картинок Sixel нет. Пользуйтесь Windows Terminal или простыми
символами. Не проверялось, какие из этих символов conhost всё же рисует через связывание шрифтов.

### ConEmu

ConEmu рисует часть символов *альтернативным шрифтом* (Settings → General → Fonts). Его диапазон по умолчанию,
`2013-25C4`, отдаёт этому шрифту, Courier New, псевдографику **и математические символы, стрелки, индексы**. В Courier New
большинства из них нет: отсюда квадратики.

Опробовано 11 октября 2026, хорошего результата пока нет:

- **Cambria Math** альтернативным шрифтом, диапазон `2070-209F;2100-23FF;27C0-27FF;2A00-2AFF;1D2C-1DBF;2C7C-2C7C;`. Рамки
  (`2500-257F`) в него не входят и остаются основным шрифтом. Все символы этого диапазона **пропали** (`∫ √ ≈ ≠ −`).
  В шрифте они есть, но высота строки по метрикам, которыми Windows подбирает размер шрифта, у него в 5,6 раза больше
  кегля (у Cascadia Mono — 1,3): вписанные в ячейку, символы теряются.
- **Cambria**, обычный шрифт из того же файла, тоже содержит все символы, высота строки 1,17. По оценке пользователя,
  который это пробовал, результат тоже так себе.

Поэтому для формул в ConEmu пока работают **простые символы** (выше) или **Windows Terminal**. Картинок Sixel ConEmu
тоже не показывает.

### MobaXterm

MobaXterm рисует шрифтом из Settings → Configuration → Terminal (*Terminal font*) и показал квадратики вместо `ₙ` и
`⩽` (скриншот пользователя, 11 октября 2026). Выберите шрифт, где эти символы есть, если такой установлен (для
математики часто советуют DejaVu Sans Mono; среди измеренных шрифтов его не было), или включите простые символы на
этом сервере.
Через `ssh` из Windows Terminal видно всё (проверено в тот же день), и картинки формул тоже.
