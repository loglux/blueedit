BLUEEDIT  -  keys and commands

Menu: F9, Alt+F/E/S/V/O/T/B/W/P or a click on the top bar.   Esc closes this screen.

FILES
  F2, Ctrl+S    Save                      Shift+F2      Save as...
  F3            Open (file picker)        Ctrl+N        New document
  In Open and Save as: F7 new folder, Alt+F1 drives, Backspace up a folder;
                Save as: Tab moves between list and name; asks before replacing a file
  Ctrl+W        Close document            Ctrl+Q, F10   Quit (asks to save changes)
  File > Info   lines, paragraphs, words, characters (file and selection), encoding
  Shift+F10     Save all and quit (for git commit and other programs that wait)
  Esc           Cancels; opened from Far it also closes the file, as Far's editor does
                (Esc in the settings goes back to the text)
                (setting "escapeQuits": "auto", true or false)

OTHER PROGRAMS
  A file changed on disk is reloaded by itself (Ctrl+Z gets the old text back);
  with unsaved edits you are asked: Reload or Keep mine.
  Command line: be file:LINE[:COL]  or  be +LINE file   (-r read-only);
  be is a short name for it.
  Set EDITOR and VISUAL to be.exe to use it from git and other programs.

ENCODINGS   A file is saved in the encoding it was read in (shown in the status line).
  Opening: UTF-8 when the bytes are valid UTF-8, otherwise Windows-1251 or DOS 866.
  File > Reopen with encoding   Garbled text? Read the same file again as another one.
  File > Convert encoding       Save in another encoding; warns about lost characters.
  File > Line endings           Switch between CRLF (Windows) and LF (Unix).

DOCUMENTS (tabs)
  F6            Next document             Shift+F6      Previous document
  Ctrl+PgDn     Next document             Ctrl+PgUp     Previous document
  Alt+1..Alt+9  Document by number        Mouse         Click a tab

MOVING AND SELECTING
  Arrows        Move                      Ctrl+Left/Rt  Word by word
  Home / End    Start / end of line       Ctrl+Home/End Start / end of file
  PgUp / PgDn   Page up / down            Shift+move    Select
  Ctrl+A        Select all                F4            Column block mode on/off
  Mouse         Click, drag to select, double click selects a word, wheel scrolls

EDITING
  Ctrl+Z        Undo                      Ctrl+Y        Redo
  Ctrl+X/C/V    Cut / copy / paste (system clipboard; pasted text is one undo step)
  Shift+Del, Ctrl+Ins, Shift+Ins   the same, as in Far and DOS
  Mouse selection is not copied by itself: Ctrl+C (Shift+drag: the terminal selects)
  Ctrl+L        Delete line               Ctrl+D        Duplicate line
  Ctrl+/        Comment lines out / in    Alt+Up/Down   Move lines up / down
  Ctrl+Bksp     Delete word before        Ctrl+Del      Delete word after
  Tab           On lines of a selection: indent them   Shift+Tab   Unindent
  Ctrl+Space    Complete the word: words of the open files and language keywords (kw)
                In code it opens by itself after 3 letters: Tab takes the word,
                Enter only after choosing with arrows (setting completeWhileTyping)
  ( [ { " '     In code the closer is added, typing it steps over it, Backspace
                removes an empty pair, over a selection it wraps (setting autoClose)
  Enter         Keeps the indent; one step deeper after ":" in Python or "{" in C#,
                JavaScript and the like; between { and } the } goes to its own line;
                a } typed on an empty line goes back to its {'s indent
  In code the bracket at the caret and its pair are underlined

SEARCH   In the dialogs: Alt+C match case, Alt+W whole word, Alt+R regular expression
  Ctrl+F        Find                      F5 / Shift+F5 Next / previous
  Ctrl+R        Replace: at each match Y yes, N no, A all the rest, Esc stop
  Alt+F7        Find in folder (list of matches; Enter opens the file at the line)
  Ctrl+G        Go to line                Regex replace: $1, $2 insert the groups
  Hotkeys and Y/N/A also work with the Russian keyboard layout.

MARKDOWN FORMATTING
  Ctrl+B        Bold                      Alt+I         Italic
  Alt+C         Inline code               Alt+D         Strikethrough
  Alt+M         Inline math $...$         Ctrl+K        Link
  Alt+H         Heading level (cycles)    Alt+L         Bullet list
  Alt+N         Numbered list             Alt+Q         Quote
  Alt+X         Task checkbox, toggles [ ] and [x]

PARAGRAPHS (text and Markdown)
  Alt+R         Reformat the paragraph (or each selected one) to the right margin
  Format menu   Align left, right, centre, justify (the last three in plain text);
                Auto-wrap: a word typed past the margin goes to a new line
  Margin: "rightMargin" in the settings (78). Alt+Z only shows long lines wrapped.

VIEW   (Alt+V, the View menu: S, L, R pick a Markdown view; themes are there too)
  Alt+Z        Soft wrap on/off          Ctrl+O        Outline / symbols
  Ctrl+E        Reading mode on/off       Alt+V S/L/R   Source / Live / Reading
  Alt+G         Line numbers on/off for every file, remembered (setting: lineNumbers)
  Live preview hides markup except on the caret line; $math$ is shown as Unicode,
  over rows when it needs them (a fraction, x^{5/2}).
  $$display$$ and \[ \] formulas are laid out: fractions, roots, limits, grids;
  in Live preview the formula the caret is in is shown as written.
  View > Formula pictures: display formulas typeset, in terminals that show Sixel
  (Windows Terminal 1.22+), with the mathimages module (docs/formula-pictures.md).
  Boxes instead of symbols: the terminal's font lacks them; Tools > Settings >
  Formula symbols: basic avoids the rarest (docs/terminal-fonts.md).
  A formula that would not typeset (an unclosed brace, \left without \right) is
  an error: TeX 1E in the status line, Shift+F7 goes to it (setting: latexCheck).
  cos without \, \cos{(x)}, 2*3, <=, ..., 5 cm in italics: warnings (TeX 1W) that F7
  fixes or never shows again (setting: latexStyle).
  Reading mode scrolls: arrows, PgUp/PgDn, Space/Shift+Space, Home/End, the wheel.
  Tables are aligned; ```cs, ```python ... blocks are coloured as that language;
  wrapped list items and quotes continue under their text.

CODE   Language servers (pyright, csharp-ls...) underline errors and warnings:
       Shift+F7 goes to the next, F7: the server's fixes or the message (LSP 2E 1W).
       After a dot the server's members are listed (m method, fld field, cls class...)
  F12           Go to the definition (another file opens)   Shift+F12   Back
  Alt+F1        What the server knows about the symbol: type, documentation
  Ctrl+F12      Format the file: by the server, or ruff/black for Python (docs/lsp.md)
  Ctrl+F2       Rename the symbol in every file (others open unsaved: File > Save all)
  Alt+F12       Where the symbol is used: a list, Enter goes there
  Tools > Code tools  installs the servers and ruff into the editor's folder
  ( ,           The function's parameters in the status line, the current in [ ]

SPELLING
  F7            Suggestions for the word at the caret (replace, add, ignore)
  F8            Spell checking on/off
  Shift+F7      Next spelling or grammar problem (selected: F7 fixes it)
  Not checked: web addresses, e-mail, paths. Words mixing Latin and Cyrillic look-
  alikes ("пpивет") are always marked; F7 offers the word in one alphabet.
  Tools > Spelling languages   Auto (the system's languages) or your own pick; a word
                               in letters none of them uses is not checked
  Tools > Spelling provider    Windows (instant), Microsoft Office or Hunspell
  Add to dictionary keeps the word in dictionary.txt next to settings.json.
  Tools > Set up grammar checking  a model here, Ollama, LM Studio, a server at an
                               address, LanguageTool or Harper; then turned on.
  Tools > Get spelling dictionaries  Hunspell's, from LibreOffice (Linux, macOS), no
                               root; those the system has are not downloaded again.
  Tools > Grammar checking     LanguageTool, a model, Edge, Chrome, Harper: findings
                               underlined in another colour; F7 shows why and the fix.
  Tools > Grammar model        which language model (Auto: the best one installed)
  A paragraph is checked in its language among the spelling ones: by its letters, else
  by a built-in model (English or German...). Markdown: "language: de" on top says it.
  Tools > Ignored rules        what F7 > Never show this hid; untick to see it again
  Formulas ($…$, $$…$$) are read with their sentence but never underlined or changed.

STYLE
  Ctrl+F7       The language model suggests a better wording of the paragraph:
                tick the changes to take (Ctrl+Z undoes them)
  Tools > Style options        what to look for: officialese, wordiness, repetition...

SETTINGS
  Tools > Settings...   The usual settings as a list: Space or Left/Right changes,
                        Enter saves and applies. Its last row opens settings.json
                        (all of them, with comments), where F2 applies the changes.
  View > Theme          DOS blue, dark or light; single colours set in settings.
  Interface language    Settings: uiLanguage auto, en or ru (menus, messages); Alt+Ф
                        and Alt+A open the same menu, whatever the keyboard layout.
  Tools > Terminal font Own Windows Terminal profile with the font, or a how-to hint.
  Tools > Command be    Puts the editor's folder in your PATH (or takes it out):
                        "be" then starts it in any new console.

OTHER
  View > Show timing: how long the last key took to reach the screen.
  Far Manager:   Commands > File associations > Edit command (F4):
                 "path\be.exe" "!.!"
